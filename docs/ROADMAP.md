# Roadmap

| 阶段 | 交付 | 验收 | 状态 |
|---|---|---|---|
| M0 | Mod 入口、审批队列、CI 与 ZIP | 编译、规则测试、游戏启动日志 | 本地编译和规则测试通过；等待 GitHub CI 及游戏启动验收 |
| M1 | 城市 ID、注册与存档 | 保存/重载/旧版本迁移 | 注册表、Scribe 存档适配器、开发者模式验证命令已实现；CI 编译与单元测试通过；等待游戏内保存/重载验证 |
| M2 | 总督提案和审批 UI | 普通建设自治、重大操作必须审批 | 未实现 |
| M3 | 道路与城区生长、施工队列 | 资源/地形合法性、取消、失败恢复 | 未实现 |
| M4 | 人口、经济与真实物流 | 无资源复制、在途货物可追踪 | 未实现 |
| M5 | 加载/未加载模拟、多殖民地、附庸和科技 | 切图一致性、性能基准 | 未实现 |
| M6 | 军团、驻军、征服与政治 | 战斗/补给/战后处置 | 未实现 |
| M7 | 可选云端策略与兼容层 | 本地回退、审批约束、Odyssey 兼容测试 | 未实现 |

未来发布：先使用 Actions Artifacts 做开发分发。正式版本将以版本标签触发独立 release 工作流，并仅对发布任务授予 contents:write；当前不创建公开 Release。
